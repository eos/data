# Analysis 2026-02
## Reconciling hadronic and partonic analyticity in $b \to s\ell\ell$ transitions

Authors: Martin Hoferichter, Bastian Kubis, Simon Mutke


### Contents

#### Ancillary Files

The files in this directory represent the fit results of the discontinuities $\text{disc} F_{2(i)}^{(7)}(s)$, where $i \in \{a,b,c,d\}$.

 - ``btosll_discontinuities.py``: Contains the functions ``f27a_disc``, ``f27b_disc``, ``f27c_disc``, and ``f27d_disc`` that provide the fitted discontinuities $\text{disc} F_{2(i)}^{(7)}(s)$.

 - ``btosll_discontinuities_create_plots.ipynb``: Creates plots comparing the fitted discontinuities $\text{disc} F_{2(i)}^{(7)}(s)$ with the exact two-loop results from [Asatrian:2019kbk](https://doi.org/10.1007/JHEP04(2020)012), provided by EOS version 1.0.16.

 - ``data``: Data files containing all data points used for the plots.

 - ``figures``: Plots of the discontinuities $\text{disc} F_{2(i)}^{(7)}(s)$ comparing the fitted results with the exac two-loop results. Both PDF and PNG formats are available.
